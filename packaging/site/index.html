brig package repository

Fedora packages of brig and NVIDIA OpenShell, built from source and signed by the brig project.

Install

sudo rpm --import https://dennisklein.github.io/brig/RPM-GPG-KEY-brig
sudo dnf install https://dennisklein.github.io/brig/brig-release.noarch.rpm
sudo dnf install brig

brig requires openshell and what it needs on the host, and brig-selinux with SELinux policy. To install only OpenShell, use sudo dnf install openshell. The gateway is openshell-gateway; the policy prover is openshell-prover. Source RPMs are in the brig-source repository (disabled by default).
